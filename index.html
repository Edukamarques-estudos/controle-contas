📘 Tutorial Rápido do Sistema

1

Lançamentos Únicos e Parcelados

Toque no botão azul + no canto inferior direito para cadastrar uma despesa ou ganho. Marque "Lançar parcelado" para gerar automaticamente todas as parcelas mensais.

2

Baixa, Reabertura e Mês Seguinte

Clique em ✓ Pagar (ou ✓ Receber) para quitar um item. O sistema oferece gerar uma cópia automática para o mês seguinte. Para desfazer, clique no ícone de reabrir e confirme.

3

Comprovante pelo WhatsApp

Em qualquer lançamento já pago, clique no ícone verde do WhatsApp no cartão para gerar e compartilhar um comprovante visual pronto para envio.

4

Personalização no ADM e Relatórios

Use o botão ADM no rodapé da tela inicial para cadastrar Tipos, Categorias, Formas de Pagamento e fazer Backup. No menu lateral (☰), gere relatórios prontos para impressão/PDF.

Tipos de Lançamento (Crédito / Débito)

Cadastre os tipos disponíveis (ex: Ganhos App, Conta Fixa, Combustível) e defina se somam ou subtraem.

Categorias

Cadastre livremente as categorias para organizar seus lançamentos.

Formas de Pagamento

Cadastre as formas de pagamento disponíveis (ex: Pix, Cartão de Crédito, Dinheiro, Boleto).

Backup & Exportação (.JSON)

Baixe uma cópia de segurança completa de todos os seus lançamentos unificados (0 registros).

Importar Planilha ou Backup (.CSV / .JSON)

Adicione registros em lote sem apagar os dados que já existem no sistema.
